# Check In Passport (interactive)

A single-page web app version of the Check In Passport for new NORAM BDRs.

**Open it:** double-click `index.html`, or host the `passport/` folder on any static site (for example GitHub Pages or an internal site). No install or internet connection is needed.

**What new hires can do**
- Set up their passport with their name, hub (New York, Atlanta or San Francisco), Day 1 date, manager and buddy
- See each week's purpose, learning objectives, schedule (shown in their own time zone, with dates), what good looks like and reflection questions
- Do every deliverable in the built-in workbook: pitch builder with a 60-second timer, LinkedIn checklist, shadowing notes, interactive payment flow with teach-back mode, ICP and DEPTH notes, ideal week planner, merchant qualification, objection bank, value statements, AE handoff note (copy to clipboard), account plan, multichannel sequence, simulation scorecard, dress rehearsal self-score, social selling portfolio and 30/60/90 plan
- Collect stamps: record who signed off each deliverable and when
- Print their whole workbook for manager checkpoints
- Practise for the three certifications by self-scoring against the rubric criteria, with timers set to the real lengths, and record each pass
- Learn payments terms with flashcards and a quiz, and add their own terms
- Keep their team's contact details and their own notes
- Graduate at Check Out with a printable boarding pass

**Good to know**
- Progress is saved in the browser on that device. Use **Backup & reset** to download a backup and restore it on another device.
- Programme content (sessions, stamps, glossary) lives in the data section at the top of the `<script>` in `index.html`. Edit it there to update the programme.
